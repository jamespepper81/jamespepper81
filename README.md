### 🔍 BitSleuth — AI-Powered Bitcoin Analysis & Wallet

> **Org:** [BitSleuthAI](https://github.com/BitSleuthAI) &nbsp;|&nbsp; **Web:** [bitsleuth.ai](https://www.bitsleuth.ai)

BitSleuth is a suite of Bitcoin-focused tools built for transparency, security, and privacy.

#### 📊 Wallet Analyzer &nbsp;•&nbsp; [app.bitsleuth.ai](https://app.bitsleuth.ai)

A web app that lets you investigate any Bitcoin address with AI-driven insights:

- **Transaction flow visualisation** — interactive graphs and flow maps
- **AI-powered explanations** — plain-language answers to questions like *"Where did these coins come from?"*
- **OPSEC risk detection** — alerts for patterns that could compromise privacy

#### 📱 BitSleuth Wallet &nbsp;•&nbsp; [Open Source](https://github.com/BitSleuthAI/Wallet)

A professional-grade, non-custodial Bitcoin mobile wallet for iOS and Android, built with React Native & Expo:

- **Complete self-custody** — private keys never leave your device
- **BIP32/39/84 compliant** — Native SegWit (Bech32) addresses
- **Advanced features** — coin control, RBF/CPFP fee bumping, biometric auth, multi-wallet support
- **Privacy first** — client-side encryption and minimal on-chain exposure
- **Licensed under AGPL-3.0** — fully open source
